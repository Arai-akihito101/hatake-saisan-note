# 畑の採算ノート
小規模農家・農産物直売者向けの無料採算計算ツール。

## 使い方
`public/index.html` がサイト本体です。収穫量、販売可能率、直売手数料、労働評価から現金収支、労働評価込み収支、黒字化に必要な収穫量・価格・販売可能率を概算できます。収穫量±20%と販売可能率±10ポイントを比較できます。端末内保存とCSV出力に対応します。

すべてブラウザー内で計算し、入力値をサーバーへ送信しません。無料・ログイン不要・外部API不使用。

## 配信構成
Cloudflare Pages: フレームワークなし／ビルド不要／公開ディレクトリ `public`／production branch `main`。静的HTMLのみでサーバー機能を使用しません。既存プロジェクトから独立しています。
